# 全面审查（2026-11-08）

> 用户要求："全面审查，确保功能完整可靠，流程清晰逻辑闭环"。
> 做法：我按使用者的完整生命周期（建档 → 导出课程 → 跟练、导出练习记录 → 周复盘 → 第 4 周之后 → 排菜单）逐步核对"输入从哪来、输出写到哪、谁来读、由哪个命令检查"；同时请一位独立审查员（只读）从同样的角度挑问题，并实际构造档案和课程去绕检查。两边的发现合在一起，逐条修订。

## 三、仍然查不出来的（agent 要自己守规矩）

- 原文是不是**这一天**的动作：检查只核对成品、周次和动作，不核对训练日。
- 左右交替的动作（死虫式、平板肩点）暂不导出。
- 每日打卡（作息、饮食）只记在周复盘的文字里，没有逐日的数据文件。
- 写成 `sh -c "…"`、脚本里再调 git 的绕法，git 命令拦截拦不住；提交前检查本身仍会运行。
- 编排器的声音和原版像不像，需要人耳试听。
