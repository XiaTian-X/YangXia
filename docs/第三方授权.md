# 第三方授权

跟练编排器打包成单个 HTML，下面这些组件都在里面。完整版权和许可文本随页面发布：打开编排器，页面最下方的"第三方授权"。文本来源是 `apps/sequencer/third-party/NOTICES.txt`，再加依赖包自带的 `LICENSE`（构建时读入）。

| 组件 | 版本 | 授权 | 怎么用 |
|---|---|---|---|
| `@lottiefiles/dotlottie-web` | 0.82.1 | MIT | 动作示意动图的播放；wasm 内嵌，不从 CDN 下载 |
| dotlottie-rs、ThorVG、RapidJSON | wasm 内 | MIT | 同上 |
| LodePNG | wasm 内 | zlib | 同上（动图没有用到图片，随引擎打包） |
| libwebp 解码部分 | wasm 内 | BSD-3-Clause | 同上 |
| jpgd | wasm 内 | 公有领域 | 同上 |
| miniz_oxide、once_cell、console_error_panic_hook、dlmalloc、hashbrown、Rust 标准库 | wasm 内 | MIT 或双授权（选 MIT） | 同上 |
| tinyrlibc | 0.5.1，wasm 内 | Blue Oak 1.0.0，个别文件 MIT | 同上 |
| `mediabunny` | 1.65.1 | MPL-2.0 | WebM 封装；未修改，源码 <https://github.com/Vanilagy/mediabunny> |

**升级这两个依赖时**：确认发布满两周、写死版本；重新查 wasm 里的组件（`strings` 能看到 `.cargo/registry` 和 `deps/thorvg` 路径），有新组件或授权变化就更新 `NOTICES.txt` 和这张表。不能随附的授权不进包。

2026-11-18 核对时读了 tinyrlibc 全部 24 个源文件的文件头、ThorVG 内第三方代码的许可文件，没有 GPL、LGPL 这类条款。ThorVG 其余文件没有逐个核对。
