# 养夏跟练编排器：和原版的功能对照

原版：`apps/sequencer/reference/原版.html`（只读，只在本地保留、不提交；单元测试用已提交的基线 `apps/sequencer/test/fixtures/original-baseline.json`）。新版成品：`npm run build` 生成 `apps/sequencer/dist/养夏跟练编排器.html`（单文件、离线可用，不提交）。

## 怎么验证没走样

- **内置语音**：固定随机种子后，三种音色共 111 个音节的合成波形和原版**逐采样一致**；24 句语音的长度一致（`apps/sequencer/test/original.test.ts`，基线由 `e2e/baseline.mjs` 从原版生成）。
- **计时**：原版四种节奏的 4 个样例课程，新版的事件时刻、打点类型、语音、总时长、SRT 条数和最后一条时间码都和原版一致。
- **成品**：Playwright 冒烟测试（`apps/sequencer/e2e/smoke.spec.ts`）打开打包好的单文件，依次导入课程、跟练、停止、导出练习记录，再导出 SRT、WAV、WebM：
  - SRT 和核心库算出的一致。
  - WAV 是 44.1kHz 双声道，时长与时间轴的误差小于 2 个采样。
  - WebM 的文件头、封装器名字、轨道、分辨率和时长正确。
  - `apps/sequencer/e2e/figure.spec.ts`：动作示意显示、关闭、跟节拍动起来；预览哪一段图就是哪一段，改了组数还对得上；跟练中改设置图和报数不错开；导出可以取消，导出中换课程不影响视频，视频里的图和同一时刻重画的一致；手写课程、改过名字、对不上的图号不显示；动图引擎失败、动图数据解不开时跟练和导出照常，并有提示；导入音乐不受内容安全策略影响；全程没有外部请求。
  - `apps/sequencer/e2e/recorder.spec.ts`：录报数声按句列这节课要说的话（不出现单字词元），用假麦克风录一句、点"停"结束、标成已录、能删。
  - 整个过程控制台没有报错。
- **听感**：音效、鼓点、压低的代码是原样移植的，自动测试只覆盖到"能导出、时长对"。**听起来和原版是否一样，还需要人听一遍。**
