# 导出跟练课程

**原样导出，不是重新编。** 组数、次数、秒数、休息、节奏全部来自成品原文，每一项都带原文出处，由检查命令逐字核对。

## 前提

- 有档案：`profiles/<代号>/档案.json`（没有就先用 `onboard`）。
- 档案能出课程：安全筛查有"是"、或 65 岁以上，`doctorCleared` 都必须是 true。否则不导出，提醒先问医生。
- 只有 8 份训练成品能导出。6–12 岁版写明"不用组数、不用次数"，全家餐饮没有训练，都不导出。

## 步骤

1. 确定成品（档案的 `product`）、第几周、哪天（A、B、C、D）。
2. 在 `templates/dist/<成品名>.md` 里找这一天做哪些动作：训练日表、"组数 × 次数"递进表、动作库。
3. 列出这份成品能用的动作：`npm run course -- moves <成品名>`，用其中的 ID 和短名。
4. 逐个动作写课程项（格式见 `docs/数据约定.md` 第一节）。
   - **mode / perSide** 照动作索引来。
   - **sets** 用本周的组数，**reps / duration** 用动作库的次数或秒数。
   - **区间取较轻松的一端**：次数、组数、时长取下限，休息取上限。
   - **rest** 照"休息"规则：大动作、小动作分档，健身房训练表里的写法是"90″"。
   - **tempo** 从这个动作的"呼吸节奏"原文里读：先下放还是先发力（start），发力、顶点停、下放、底部停各几秒。第 3 周起写了"下放 3 秒"的，用 3 秒。
   - **quote** 摘出组数、次数、休息所在的那几句原文（最多 4 段）。每段只摘**本周那一句**，不要摘同时写了几周的长句。
   - 循环（如居家版 D 日）用 `kind: "circuit"`，写 rounds、restBetweenRounds。
5. 存到 `profiles/<代号>/课程/第N周-X日.json`。
6. **检查**：`npm run course -- check profiles/<代号>/课程/第N周-X日.json --profile profiles/<代号>/档案.json`。
   - 有错误就**按原文改**：换成正确的原文、取正确的数字。**不能为了通过检查去改数字或删动作。**
   - 0 个错误才能交给使用者。
7. 告诉使用者：
   - 课程总时长：`npm run course -- summary <文件>`。
   - 怎么用：先 `npm run build`，再双击打开 `apps/sequencer/dist/养夏跟练编排器.html`，导入这份 JSON，可以跟练，也可以导出音频、字幕、视频。
   - 热身、拉伸、有氧（单车、跑步机）不在课程里，照成品做。
   - 左右**交替**做的动作（死虫式"每侧 12 次"、平板肩点"每侧 10 次"）课程格式还表达不了，暂不导出，照成品做。
   - 练的时候疼、头晕、胸闷，马上停下。

## 不做

- 不加成品里没有的动作，不改次数和强度。
- 不把第 4 周的处方用在第 1 周。
- 不导出筛查没过的人的课程。
