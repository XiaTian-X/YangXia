# 导出跟练课程

**用命令从训练单导出，不手写处方。** 组数、休息来自训练单；次数、难度级、重量来自档案的个人进度；节奏来自呼吸节奏原文和难度级；条件变体、器材、轮换按档案。我只选哪一天。

## 前提

- 有档案：`profiles/<代号>/档案.json`（没有就先用 `onboard`），而且 `npm run profile -- check profiles/<代号>` 没有错误。
- 档案能出课程：安全筛查有"是"、65 岁以上、40–64 岁体检或血压没确认、65 岁以上摔倒过，都要有**有效的**医生同意（`doctorCleared` 为 true，`doctorDate` 不早于最近那件事）。否则不导出，提醒先问医生。
- 档案检查说"做触发评估"的（跨段、满一年、断了 28 天以上……），先用 `assess` 做。
- 65 岁以上：每次导出前问一句"上次练完以后有没有摔倒过"，摔过就先用 `assess` 做触发评估"摔倒"，暂停平衡练习，医生同意以后再练。
- 8 份起始期训练成品和它们的稳定期成品有训练单（稳定期的训练单由起始期派生，不新写处方）。6–12 岁版写明"不用组数、不用次数"，全家餐饮没有训练，都不导出。
- 模板要有训练单（`templates/dist/data/plans.json`）；没有就提示先更新模板仓库。
- **每次导出之前，先问有没有新的练习记录**（上次练完保存或分享回来的 `养夏_练习记录_….json`），有就先导入（见下面"练习记录回来"）。找级、退回要在两次导出之间改进度，记录不导入，档案检查看不到这一段的不适，就挡不住往上调。

## 步骤

1. 确定第几周、哪天：周次**不能超过**档案 `segments` 最后一项的周次（下一周要等 `weekly-review` 放行）；这一段有哪几天，命令会提示（减量段有合并日，如 `B+C`）。稳定期的周次写 1–12，导出的是这一轮对应那一周的处方（第 5、9 周 = 第 1 周……）；不能回头导出上一轮后面更重的周（第 5 周导不出第 4 周）。
2. 档案缺什么，先问使用者再记，不要替他选：
   - 训练单里"按器材选一个"（桌下划船 / 门框划船 / 低单杠……）：档案的 `choices` 里没有能用的，命令会拦下。问清楚家里有什么，写进 `choices`，写训练单里的原样：动作 ID，或带括号的占位（居家版 `（门框划船）`、13–17 岁 `（毛巾划船）`，导出时列在"照成品做"）。换了场地或成品要重新核对。
   - 条件（高血压、骨质疏松、家里有没有别人、有没有地方跳、家长在不在旁边）：没记的按保守版本导出。使用者愿意说的，按 `onboard` 的说法记进 `conditions`，只记是 / 否。
   - 播放偏好（v4 阶段 8）：使用者说不要呼吸提示、想在每次做完时报数（默认是每次开始时报），记进档案的 `playback`（`breathLead`、`breathAfter`、`countTiming`，取值见 `docs/数据约定.md`），只记选择。命令会写进课程；65 岁以上、有高血压或没确认的人领完以后至少响提示音，档案写了"安静"也按提示音导出（命令会提醒），照实告诉使用者——想安静的成人，先在建档或复查时确认有没有高血压。
3. 导出：`npm run course -- export profiles/<代号> <第几周> <哪天>`。
   - 轮换（健身房 A6、A7 每次换一个；13–17 岁核心每周换一个）按规则自动选；使用者想换，用 `--pick 组名=动作 ID`。
   - 命令会先检查整个档案目录（档案、周复盘、个人进度日志），再导出，再跑一遍课程检查，0 个错误才写文件，默认存到 `profiles/<代号>/课程/第N段-第N周-X日.json`（半量课是 `…-X日-半量.json`）。
   - 同时出**课程包** `课程/<代号>-第N段-第N周-X日.html`：打包好的编排器里嵌了这节课，打开就能练，不用再导入 JSON。编排器没打包、代码改过没重新打包、动图和模板对不上时，命令只出 JSON、删掉同名的旧课程包，并说原因——照提示先 `npm run build` 再重新导出。
   - 命令提示"每次练之前确认"的（家长在不在旁边、家里有没有别人），照原话提醒使用者：当天和档案记的不一样，就照成品原文换做法。
   - **中断、生病回来的第一次**：命令提示"断了 N 天"的，或者使用者说刚生病好（成人退烧后 48 小时、13–17 岁退烧后再等 2 天），加 `--half` 导出半量课（每个动作组数减半向上取整，次数、秒数、休息不变）。照成品"不补作业、不清零、不从头再来"，周次不动；半量课照样算训练次数，但不当加量依据，复盘数据写 `half: true`。
   - 有错误就**改档案里错的地方**（器材、进度没按规则改），不改训练单、不手改课程。进度只能按 `weekly-review` 的规则经 `progressLog` 改。
4. 告诉使用者：
   - 命令列出的**照成品做**的项：交替动作（死虫式、平板肩点）、等长对抗（毛巾划船）、YTW、有氧和单车、原文有歧义的减量日、起始级是"屈髋练习"这类做法不同的级……照原文转告，让使用者看成品那一节做。
   - **本周不做**、**有时间可以加**、**时间不够先砍**的，也照命令的提示说。
   - 选了减脂的，命令还会打出"减脂：这一周有氧合计多少分钟"（或者"先问医生，照保持的量"），照原话说，训练里的有氧算进去。
   - 命令打出的"有氧：这一周做稳态 / 间歇"（健身房还有每次多久）和原因，照原话说（有氧不导出，只能说对）：徒手、居家有高血压或没确认、没问过医生的一直稳态，这一轮第 2 周的稳态自查没过、没记的也是稳态；健身房有高血压或没确认、没问过医生的保持第 2 周的强度（每次 15 分钟、坡度不再往上加）。
   - 课程总时长：`npm run course -- summary <文件>`。
   - 照命令打出的"声明"告诉使用者：课程按**未经专业审核**的计划模板生成，不是医学建议，不能替代医生的判断。
   - **怎么用课程包**：电脑上直接双击课程包。到手机上：把课程包**发给自己**（文件传输助手、AirDrop、数据线），不要发到群里——课程包里只有这节课的内容，但文件名带代号。手机上**先保存文件，再用浏览器打开**（安卓用 Edge、夸克这类从文件管理器打开；聊天软件里直接点开不一定能运行；iPhone 没测过，打不开就先用电脑练）。新的课程包到了就把旧的删掉。可以跟练，也可以在"更多"里导出音频、字幕、视频。画面上有合适示意图的动作会显示动图（只帮助看清动作，不是医学建议）；难度级和图对不上的动作不显示，这是正常的。
   - **练完填练习记录**：跟练结束（或中途结束）后是"练完了"页，选整体感受、有没有不适；第 1–2 周找级的，在"每个动作"里照计划原话选这一组的感受；健身房填"还能做几下"；升级后做不到就勾"当场退回"；备注不写病名、用药、血压体重数字。点"保存练习记录"或分享按钮，把 `养夏_练习记录_<日期>_<时分>.json` **发回电脑**（同样发给自己），告诉我文件在哪。
   - 热身、拉伸不在课程里，照成品做。练的时候疼、头晕、胸闷，马上停下。
5. **练习记录回来**：使用者告诉我记录文件在哪，用命令导入，**不手抄、不手动挪文件**：
   - 先看：`npm run profile -- import profiles/<代号> <记录.json>… --dry-run`，看校验结果、不适、备注、要写到哪。备注里有病名、用药、血压体重数字的，问使用者删掉那几句（改原文件里的备注）再导入。
   - 再导入：`npm run profile -- import profiles/<代号> <记录.json>…`。命令校验格式、核对是这个档案导出的课、去重，按格式写进 `打卡/`，导完跑一遍档案检查。
   - 命令打出"【注意】这次有疼痛 / 头晕 / 胸闷"的，照原话告诉使用者（下周不加量，按成品"疼了怎么办"处理，必要时就医）；被拒收的记录有不适，周复盘时照实写进复盘数据的 `symptoms`。
   - 拒收"练的不是档案里导出的课程"：样例课、手写的课不进档案。一家人用同一份成品同一天的课，课程 id 一样，命令分不出是谁练的——导入前问清楚这份记录是谁的。
   - 同一次练习已经导入过、内容不一样（比如后来补报了不适）：命令列出哪里不一样；问过使用者确实要换，加 `--replace` 原地覆盖（文件名不变，进度日志引用的依据还在）。记下的疼痛、头晕、胸闷和"手改过的课"不能改成没有：使用者说当时点错了，照实写进周复盘，不改记录。档案里旧的那份格式不对的，先改好它，或者问过使用者用 `--replace` 替换。
   - 导入成功后提醒：原文件还在下载目录、手机、聊天记录里，可以删（个人数据只放在 `profiles/`）。agent 读记录时内容会作为对话发给模型服务处理，照实告诉使用者。
   - 复盘过的那一周来了新记录，档案检查会报那一周的复盘数据（训练次数、有没有不适）要改：交给 `weekly-review` 照实改。
6. 想看这一周整周的安排：`npm run course -- plan profiles/<代号>` 生成**现在这一周**的个人计划单 `计划/第N段-第N周.md`（每天的动作和组数、照成品做的项、有氧、每日习惯达标线、下次评估的日期）。由命令生成，开头带声明，**不手写、不手改**（档案检查会重新生成比对）；进度改了就重新生成。
7. 第 1–2 周找级（稳定期只有直接进入的人的第 1 轮、真的断了四周以上做过触发评估回来的头 14 天能找级，依据要是回来以后练的那一次）：使用者练完、练习记录里选了"做到上限还很轻松"或"做不到下限或后面几下变形"，下一次导出前在档案里按 `weekly-review` 的"找级"规则改一级（`progressLog` 写依据），再导出。

## 不做

- 不手写、不手改课程的组数、次数、秒数、休息、节奏（课程检查按训练单逐项核对，改了会报错）。
- 不替使用者选器材、不替使用者判断有没有高血压这类条件；没问到的按保守版本。
- 不导出筛查没过的人的课程。
- 训练单导不出的（照成品做），不自己补成课程。
- 不手抄练习记录、不手动把记录文件放进 `打卡/`，一律用 `profile import`。
