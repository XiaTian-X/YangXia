# 排菜单

只用**全家餐饮模板**（`templates/dist/全家餐饮模板.md`）和三餐菜谱手册里已有的菜、份量和换算方法，不新编菜谱和营养数字。

## 先问清楚

- **菜单放在谁的目录下**：放在提出排菜单的那个人的档案目录 `profiles/<代号>/菜单/`。还没有档案就先用 `onboard` 建档。
- **家庭成员**：年龄段（照模板的成员表分：小学生、初高中生、成人、老人）、人数。只记代号，不记真名。把每个人的年龄段（a06、a13、a18、a40、a65，含档案主人自己）写进档案的 `household`；菜单检查按这些年龄段的红线查，家里有孩子就不能写体重、减重。
- **成员表里"先问医生或营养师"的情况**：食物过敏、医生开的饮食要求、咀嚼吞咽困难、怀孕哺乳、吃华法林、5 岁及以下的孩子。
  - 有的照模板第一章处理：单独调整、整道菜不做、或者先问医生。
  - 不替医生定饮食要求。

## 步骤

1. 份量按模板的"每人每顿吃多少"和"一锅菜怎么分着盛"。
2. 人数和模板默认的 4 口之家不一样时，按模板第六章的**人数换算**方法算采购量。
   - `python3 templates/tpl.py meal` 是模板维护工具，写死了 4 口之家，只能用来核对 4 口之家的数。
3. 菜从模板的一周示例菜单、菜谱手册和食材交换表里选；外食照外食指南。
4. 写到 `profiles/<代号>/菜单/第N周.md`：开头一行写声明 `> 本计划由养夏计划模板生成，未经专业审核，不是医学建议，不能替代医生的判断。`（目前没有专业人员审核，没有这一行检查会报错）；然后每天三餐、每人份量、采购清单，注明出自模板哪一节。
5. **检查**：`npm run profile -- check profiles/<代号>`。
   - 菜单文字按全家餐饮的红线检查：不写千卡、热量赤字、减肥、节食。
   - 也按 `household` 里每个家庭成员的年龄段检查（家里有 6–12 岁、13–17 岁的孩子，不写体重、减重、热量）。
   - 0 个错误再交给使用者。

## 选了目标的人（v4 阶段 4）

- 只写**档案主人自己**那一份，照全家餐饮模板"主食按自己计划调整，菜全家一样吃"和"一锅菜怎么分着盛"：
  - 这一周按减脂的：写"你那一份肉少盛一些、主食少半个馒头"（女性只写肉少盛一些，主食不减）；
  - 这一周按增肌的：写"你那一份主食多半个到一个馒头"；
  - 安全筛查第 3 项（糖尿病、肾病、痛风或高尿酸、高血脂）答"是"的：不写他那一份的增减（吃照医生的意见）。
- **菜单里不出现"减脂""增肌""千卡""减肥"**（全家餐饮的红线，`profile check` 会拦），只写份量。全家同锅的油分不开，如实说菜单上能少的有限，其余靠自己。
- **不写家里其他成年人的目标**：菜单放在提出排菜单那个人的档案里，写别人的目标等于告诉了他。

## 不做

- 不推荐补剂和剂量，不说"少量饮酒有益"。
- 不算热量，不给孩子定减重目标。
- 低钠盐：照模板原话（家里想换低钠盐，先问医生）。
