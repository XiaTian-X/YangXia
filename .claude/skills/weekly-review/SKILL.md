# 周复盘

只按**成品写的规则**判断，不自己定加量幅度。

## 读什么

1. `profiles/<代号>/档案.json`：成品、第几周、开始日期。
2. 这周的练习记录 `profiles/<代号>/打卡/*.json`（yangxia.session/1），以及使用者自己说的打卡情况（成品里的每日打卡表）。
3. 成品里的规则（`templates/dist/<成品名>.md`）：
   - 每日达标线、每周达标线、四周成功线（"达标线"一节）；
   - "什么时候升级"（40–64 岁版有单独一节，**这一轮不升级**的规定照做）；
   - "疼了怎么办"；
   - 下一周训练日表和递进表。

## 先看不适信号

练习记录里 `symptoms` 有 true，或者使用者说疼、头晕、胸闷：

- **下周不加量**，照成品"疼了怎么办"处理：换动作、减幅度、停这个动作。
- 胸痛、胸闷、心慌、头晕到站不稳：建议**尽快就医**。没看过医生之前，不出下周课程。
- 记在复盘里，下次先问恢复了没有。

## 再看达标

- 照成品的达标线，算这周完成了几练、几天达标。
- 达标：按"什么时候升级"进入下一周的安排。
- 没达标：照成品说的处理（通常是重复本周，或者原样继续），**不加量**。
- 感觉"吃力"：不加量；成品有"还能做几下"的余力标准的，照它判断。

## 写下来

1. `profiles/<代号>/复盘/第N周.md` 写四件事：
   - 这周完成情况；
   - 有没有不适、怎么处理的；
   - 下周做什么，每一条注明出自成品哪一节；
   - 要提醒的事。
2. 档案的 `week` 改成下一周。
3. **检查**：`npm run profile -- check profiles/<代号>`。
   - 复盘文字也要过这个年龄段的红线，比如 6–12 岁、13–17 岁不谈体重和热量。
   - 0 个错误再交给使用者。
4. 要跟练的话，用 `course-export` 导出下周的课程。
