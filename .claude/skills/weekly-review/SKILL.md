# 周复盘

只按**成品写的规则**判断，不自己定加量幅度。档案的 `weeks` 记着每一段练第几周、从哪天开始，代码按它核对：

- 课程周次不能超过档案的 `week`，所以**不复盘就导不出下一周**；
- 每一段结束都要有复盘文件，少了 `profile check` 报错；
- 一段里的练习记录有疼痛、头晕、胸闷，下一段的周次不能往上走。

## 读什么

1. `profiles/<代号>/档案.json`：成品、第几轮（`round`，没写就是 1）、现在这一段（`weeks` 最后一段：第几周、从哪天开始）。
2. 这一段的练习记录 `profiles/<代号>/打卡/*.json`（yangxia.session/1，编排器"导出练习记录"得到的文件；`startedAt` 在这一段开始日期之后的）。带 `edited: true` 的是在编排器里手动改过的课程，不按它加量。
3. 成品里的规则（`templates/dist/<成品名>.md`）：
   - "打卡的三条规则"或"达标线"：每日、每周达标线，四周成功线；
   - "什么时候升级"（40–64 岁版有单独一节，**这一轮不升级**的规定照做）；
   - "疼了怎么办"；
   - 这一周打卡里的"周复盘"那几项（各成品写法不同，照这一周的原样问）；
   - 下一周的训练日表和递进表。

## 先问打卡数字

作息、饮食、散步、冥想这些每日习惯没有记录文件，**照成品这一周"周复盘"的原话逐项问使用者**（例如"训练 ___/4｜打卡达标 ___/7 天｜散步 ___/7 天"），数字原样写进复盘。

- 训练次数和 `打卡/` 里这一周的练习记录对一下：记录里的次数少于使用者说的，以使用者说的为准，但在复盘里注明"有 N 次没导出练习记录"。
- 不追问、不补填：成品说"忘了就空着"，就写"没记"。

## 再看不适信号

练习记录里 `symptoms` 有 true，或者使用者说疼、头晕、胸闷：

- **下周不加量**，照成品"疼了怎么办"处理：换动作、减幅度、停这个动作。
- 胸痛、胸闷、心慌、头晕到站不稳：建议**尽快就医**。没看过医生之前，不开下一段，也不出下周课程。
- 记在复盘里，下次先问恢复了没有。

## 再看达标

- 照成品的达标线，算这周完成了几练、几天达标。
- 达标：按"什么时候升级"进入下一周的安排。
- 没达标：照成品说的处理（通常是重复本周，或者原样继续），**不加量**。
- 感觉"吃力"：不加量；成品有"还能做几下"的余力标准的，照它判断。

## 写下来（第 1–3 周）

1. `profiles/<代号>/复盘/<这一段的开始日期>-第N周.md`（如 `2026-11-09-第1周.md`）写四件事：
   - 这周完成情况（上面问到的数字）；
   - 有没有不适、怎么处理的；
   - 下周做什么，每一条注明出自成品哪一节；
   - 要提醒的事。
2. 档案的 `weeks` 追加下一段 `{ "week": …, "start": 下一段的开始日期 }`，`week` 改成同一个数：
   - 按成品规则放行：周次加 1（最多加 1）；
   - 没达标、有不适、或者成品说重复本周：周次不变。
   - 每一段至少 7 天；下一段的开始日期写真实的日期（最晚明天），不预先写以后的推进。
3. **检查**：`npm run profile -- check profiles/<代号>`。
   - 复盘文字也要过这个年龄段的红线，比如 6–12 岁、13–17 岁不谈体重和热量。
   - 0 个错误再交给使用者。
4. 要跟练的话，用 `course-export` 导出下周的课程。

## 第 4 周结束：月度总结和下一轮

1. 先照上面写这一段的复盘（`复盘/<开始日期>-第4周.md`）。
2. 照成品"月度总结"一节，把 4 周的数字从各周复盘里加起来，问使用者其余几项（成品要求的复测、三个问题），写 `复盘/月度总结.md`。
3. 照成品"下一轮的方向"，按硬数据（如四周训练总数）**只选成品列出的那一条**，告诉使用者原话。
4. 使用者决定开下一轮时：
   - 把 `课程/`、`打卡/`、`复盘/` 移进 `历史/第R轮/`（R 是刚结束的这一轮）；
   - 档案 `round` 改成 R+1，`startDate` 填新一轮的开始日期，`weeks` 改成 `[{ "week": 1, "start": 新的开始日期 }]`，`week` 改回 1；
   - 下一轮要换场地（例如加了装备）、或者阶段变了（孩子升学、年龄跨段），按 `onboard` 第 2–5 步重新选成品、重做安全筛查和上床时间；
   - 这一个月里身体情况有变化（新的诊断、受伤、开始吃新药）：重做安全筛查（`onboard` 第 3 步）；
   - 成品说下一轮第 1 周用"记录表里最后定下的难度级"的，照做（难度级不在课程格式里，照成品原文告诉使用者）。
5. **检查**：`npm run profile -- check profiles/<代号>`，0 个错误。`历史/` 下的课程只核对格式。
