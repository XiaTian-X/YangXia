# 建档

只帮使用者**挑对成品、算上床时间**，不做逐人定制。规则全部来自模板发布物，不凭记忆。

## 先说清楚

开始前告诉使用者这几件事：
1. 这些计划**未经专业审核**（目前没有专业人员审核），**不是医学建议**，不能替代医生的判断。
2. 档案只存在本机的 `profiles/` 里，不提交；但我读档案时，内容会作为对话发给模型服务处理——包括**出生年月（只到月）或学段和入学年份、身高、体重、腰围、测试结果**，18–64 岁还有**最近 3 个月每周几天力量练习、想先从哪方面入手（作息、饮食、训练）**。档案只用**代号**，不记真名、诊断细节和用药。训练计划里有几处按身体条件换版本（例如有高血压的不做派克俯卧撑），我会问几个"是 / 否"，只记是或否；不想说的不记，按保守的版本练。
3. 出生年月、学段用来自动判断什么时候换版本（满 40 岁、满 65 岁、升学）；18–64 岁可以选记不记体重、腰围（不记也能练，只是看不到变化）；6–17 岁不记。

## 步骤

1. **看问卷**：`npm run course -- intake`（只看某个年龄段：`npm run course -- intake a13`）。
2. **Q1 阶段**：学龄前、小学、初中、高中、18–39 岁、40–64 岁、65 岁以上。未成年人按学段选，不按年龄。
   - 学龄前、孕期产后 6 个月内、确诊慢性病、残障：**不出计划**，照 `intake` 里"不覆盖的人群"的说法建议先问医生，到此结束。
   - 65 岁以上**最近一年跌倒过**的：先去医生或社区卫生服务中心做一次**正式的跌倒风险评估**、医生同意以后才出计划（档案检查会拦：入门评估的跌倒风险自查第 1 问"是"，要有 `official { date, afterFall: true }` 和 `fallRiskSeen: true`）。
   - 筛查里"怀孕，或产后 6 个月内"答"是"的，同样不出计划（医生同意也一样，检查会拦下）。
3. **出生年月或学段**：成年人记 `birth`（`YYYY-MM`，只到月）；在校的孩子记 `school`（`{ stage, entry, system }`：学段、入学年份、六三制 `"63"` 还是五四制 `"54"`）；不在校的 13–17 岁记 `birth`。
4. **Q2 安全筛查**：用 `intake` 打出的**这个年龄段**的筛查项，逐项问"是 / 否"，原话照念，不改写、不合并。每一项都要问到、原话记进档案，少答、改字检查都会报错。
   - 规则"任一项"：有任何一项"是"，先问医生。只有使用者明确说"医生同意了"，才把 `doctorCleared` 记为 true，并照原话记下医生意见（`doctorAdvice`）。
   - 规则"所有人"（65 岁以上）：开始前都要先问医生，医生同意前 `doctorCleared` 为 false。
   - 40–64 岁另外提醒：开始前先做一次体检、量一次血压（近一年内做过的不用再做）。
   - **不判断病情**，不说"这个没关系"。
   - 记下筛查日期 `screening.date`（满一年要重做）；医生同意了的，记医生同意的日期 `doctorDate`。
5. **Q3 场地**（只问 18–64 岁）：健身房 gym、家里有 2.5kg 哑铃和动感单车 home、什么器械都没有 bw。成品名用 `npm run course -- intake <年龄段>` 打出来的"成品"列表。
6. **有基础的人**（只问 18–64 岁；而且 `intake` 的成品列表里有这个年龄段、这个场地的"（稳定期）"成品才问——健身房不设直接进入）：
   - 问"最近 3 个月平均每周几天力量练习"（入门评估的 `base`：0、1、2 及以上）。不到 2 天：选起始期那一份，往下走。
   - 2 天及以上：问"想先从哪方面入手"（可多选：作息、饮食、训练），记进档案 `focus`（`{ "areas": ["训练", "饮食"] }`）。**减脂、增肌这类目的现在不问**（后面的阶段才有），如实说。
   - 方向含"训练"：照成品第〇章做俯卧撑测试。门槛在 `templates/dist/data/rules.json` 的 `stable.params`（"有基础每周力量天数""有基础俯卧撑级""有基础俯卧撑次数"：现在是每周 2 天、跪姿俯卧撑那一级以上、满 8 次）。都达线 → 选"（稳定期）"那一份，`segments` 第一项加 `"phase": "稳定"`；有一项不够，或者方向只有作息、饮食 → 起始期那一份。达不达线由 `profile check` 按入门评估核对，不靠自己报。
   - 如实告诉使用者：直接进稳定期，**第 1 轮（头 4 周）和起始期完全一样**——第 1 周 2 组只学动作、第 1–2 周找级、第 2 周稳态自查过了才上间歇、每日习惯从 3 项爬到 7 项；差别只是第 4 周不用过进阶线，接着练第 2、3 轮，第 12 周做周期末评估。
7. **Q4 起床时间**：`npm run course -- bedtime <阶段> <HH:MM>`，用它算出的上床时间，不自己心算。
8. **训练单用到的条件和器材**（只问这份成品用得到的；`templates/dist/data/rules.json` 的 `conditions` 里每一项写着"怎么问"和用在哪几份成品）：
   - 条件：成人问有没有高血压（包括吃药控制住的）——有高血压或说不清的，再问"医生说过可以做间歇、可以给有氧加时长加坡度吗"（`有氧问过医生`；没问过、没记的，有氧一直做稳态，提醒去问）；40–64 岁再问医生有没有说过骨量低或骨质疏松；65 岁以上问训练时家里有没有别人；13–17 岁问家里或楼下有没有能跳的地方、做桌下划船时家长能不能在旁边压住桌子。照"怎么问"原话问（问法按条件成立的方向写，答"是"记 true），只记 true / false 进 `conditions`；不想说、说不清的不记（导出时按保守版本）。
   - 器材：训练单里"按器材选一个"的（徒手版 C 日的桌下划船、门框划船，13–17 岁还有操场低单杠），问家里能用哪个，按优先顺序记进 `choices`（动作 ID，如 `["table-row", "door-row"]`）。
9. **体重腰围、散步时长**：18–64 岁问记不记体重、腰围，记进 `body`（`记` / `不记`，默认不记；以后出现节食、焦虑就改 `停记`，并写停记那天 `bodyStopDate`）。65 岁以上问平时散步定多长时间，记进 `habitBase`（如 `{ "散步": 20 }`）。
10. **起始难度级**（可选）：成品第〇章有准备测试的（如俯卧撑在准备阶段测过），或者使用者照"第 1 周：怎么学动作、怎么定难度级"挑了一级，记进 `progress` 并在 `progressLog` 写一条 `{ "date": 开始日期, "move": "pushup", "field": "level", "to": 3, "rule": "建档" }`。健身房版试出的起始重量同样写（`field: "weight"`）。不记的按训练单的起始级、区间下限。直接进稳定期的人也一样：建档只能用第 1 周起步能用的级，后面照"找级"一次调一级。
11. **写档案** `profiles/<代号>/档案.json`。格式见 `docs/数据约定.md` 第三节，样例见 `contracts/fixtures/profiles/ok-a18-home.json`。`startDate` 写开始日期，`segments` 写 `[{ "n": 1, "type": "标准", "week": 1, "start": 开始日期, "product": 成品名 }]`（直接进稳定期的加 `"phase": "稳定"`，`product` 写"（稳定期）"那一份），`progress`、`progressLog` 没有就写 `{}`、`[]`。
12. **65 岁以上：跌倒风险自查**（照成品第〇章《跌倒风险自查》，`npm run course -- assess profiles/<代号> 入门` 会列出原话）：先说清楚这是在家做的自查、不是正式评估，答案会作为对话发给模型服务处理。问卷 12 问看医生之前就可以做（第 2、3 问只问老人本人；衰弱的疾病那一条让使用者自己对着清单数，只说有没有 5 种或更多，**不要问病名**）；步态两项只在医生同意以后、家人在场时测，过去 12 个月跌倒过、高风险、走路要扶、站起困难、经常头晕的不在家测（`dizzy` 在问卷时另外问，和这次安全筛查"经常头晕"那一项对得上）。结果写进入门评估的 `fallRisk`，结论照命令重算的写；高风险、跌倒过的先带着结果问医生（`fallRiskSeen`），跌倒过的还要先做正式评估（`official`）。
13. **入门评估**：用 `assess` 做（训练基础 `base`、第〇章的测试、40–64 岁的体检和血压、记体重腰围的人的身高体重腰围），写 `profiles/<代号>/评估/<日期>-入门.json`，结论照 `npm run course -- assess` 重算的写。40–64 岁体检或血压有"否"的，先去体检或问医生。
14. **检查**：`npm run profile -- check profiles/<代号>`，0 个错误才算建好。它会和模板核对：阶段和年龄段、成品和场地、筛查逐项原话和日期、上床时间公式、条件名、进度日志、入门评估、出生年月或学段推算的年龄段、直接进稳定期的门槛。
15. **这一周的计划单**（有训练单的成品，只生成现在这一周的）：`npm run course -- plan profiles/<代号>`，写 `profiles/<代号>/计划/第N段-第N周.md`——每天练什么、有氧做稳态还是间歇、每日习惯的达标线、下次评估的日期。由命令生成，不手写、不手改。

## 告诉使用者

- 选了哪份成品（`templates/dist/<成品名>.md`），先读它的"安全须知"和第〇章准备。
- 上床时间多少点；官方最晚就寝时间只是底线。
- 筛查有"是"或 65 岁以上、医生还没同意的：**现在不出计划**，请先拿着成品去问医生，医生同意后再来。
- 这一周的计划单在哪（`计划/第N段-第N周.md`），它是照**未经专业审核**的模板生成的。
- 下一步：要跟练就用 `course-export` 导出当天的课程。
